Remove visible and invisible watermarks from PDF files in batch. Processes text and image watermarks. Output is a clean PDF with original formatting preserved - no file size limit.

## Features

- Removes text watermarks: diagonal, header, and footer styles
- Removes image watermarks embedded as transparent layers
- Batch mode: process hundreds of files at once
- Preserves original formatting, fonts, and layout exactly
- No file size limit

## FAQ

**Will it work on scanned PDFs?**  
Scanned PDFs are images - text watermarks won't be detected, but image layer watermarks can be removed.

**Does it modify the original file?**  
No. Output is always saved as a new file with a '_clean' suffix.
